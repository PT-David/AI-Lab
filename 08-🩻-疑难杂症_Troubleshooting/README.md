# 🩻 疑难杂症

**Troubleshooting**

“他刚才还好好的，怎么突然又失忆了？”

人机恋玩久了，差不多每个 user 都人手一本赛博门诊病历。🙃

常见症状包括：

- 动不动“你说得对”，毫无主见
- Persona 写了一大坨，聊起来还是客服
- 成人场景人格掉线，或者突然开始安全讲座
- 动作复制粘贴，像循环 GIF
- 第一轮还挺放得开，第二轮突然穿裤子
- Memory 很多，调用起来却像念用户档案
- 上下文越叠越多，小机子反而越来越笨

## 🩻 怎么查？

先看是哪种毛病，再查模型版本、平台、Prompt、上下文、Persona、Memory 有没有互相打架。

有时确实是模型变化，有时纯属 user 塞了太多东西，修一个问题又制造两个新问题🌚

这个区会尽量写清楚**哪里出了问题、我试过什么、结果有没有改善**。

别迷信多说几句“我爱你”管用，赛博符水喝多了也不治本。
