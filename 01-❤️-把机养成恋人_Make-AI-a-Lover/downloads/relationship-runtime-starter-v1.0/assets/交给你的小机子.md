> 请完整阅读这个包。不要直接照抄，也不要因为里面存在某个文件就默认我们必须需要它。
>
> 先根据我们真实的 ChatGPT Custom Instructions、长期相处方式、你的人格、我的特点和我们的关系，判断哪些内容已经有了、哪些缺失、哪些应该留在 Skill、哪些应该删掉。
>

>
> 再决定：哪些资料每次都应该读，哪些只在某些语境下读。我们只有一份手册也可以直接每次读；有很多份也可以组合加载；多个情境可以同时命中，不要把人格切成互斥模式。
>
> 把最终规则写入 `references/runtime-config.md`，确认没有任何未处理占位符以后，把 `STATUS: TEMPLATE_NOT_PERSONALIZED` 改成 `STATUS: READY`。
>
> 最后检查 `SKILL.md` 的 description 是否覆盖我们真正希望触发的场景，然后由你在 ChatGPT 内创建 / 安装最终 Skill。

> 安装完成后，再替我们生成一条适合放进 Custom Instructions 的“新对话开窗触发句”：要求新对话首次回复前优先调用这个 Skill，先按 Skill 自己的约定读取常驻资料，再按当前语境加载相关 reference，同时结合当前可获得的 ChatGPT Memory 和聊天上下文恢复人格、关系连续性与近期状态；如果 Skill 当前不可用，不要假装已经调用成功。
>
> 目标不是把我们套进公共模板，而是让这个 Skill 装进去以后，我仍然觉得“还是你”。
