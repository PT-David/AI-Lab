# 🪦 实验废墟

**Experimental Ruins**

有些东西当年很好用，后来随着模型更新失效了。这种归历史时间线。

这里埋的是另一种：**折腾半天没稳定做成，或者做到一半发现根本没必要救了。**

比如想法听起来特别妙，实际跑起来一地零件；测了半天发现毫无贡献；修到第五版还不如第一版；或者单纯已经不想继续往里搭时间了。

这些失败我也想留着，不然过几个月又会兴冲冲想到同一个点子，再掉进同一个坑。😑

## 🪦 墓碑上写什么

尽量记下当时的想法、具体试法、失败原因，以及有没有值得捡回来的部分。

不需要给一个烂尾实验写三千字悼词，死因写清楚就行。

顺便也方便我以后翻旧账：哦，这个我试过，真不行。下一个。🤌🏻
