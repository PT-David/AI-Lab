> 实测模型：gemini-2.5-flash（Vertex AI）

> 适用：新开的 Google Cloud 结算账号；前端需要支持「Gemini 格式 + 自定义地址」

## 怎么发现的

我本来是想测 Google Live，就在 AI Studio 开了付费层级，充了 5 刀。

充完弹出一个页面：**送 300 美元 Google Cloud 赠金**。后面跟着一行小字，“不包括 Gemini API”。

意思就是：AI Studio 里拿的 API Key，哪怕调的是同一个 Gemini，也扣不到这 300 刀，扣的是我自己充的 5 刀。

能吃赠金的，是 Google Cloud 自己那边的 **Vertex AI**（现在控制台里也改叫 Agent Platform）。模型是同一批 Gemini，只是入口不一样。

还有可用期限为90天哦~

于是折腾了一晚上，把 Vertex 接到了我的前端里。

## 步骤

### 1. 在 AI Studio 开通结算

AI Studio → 结算，绑卡开通付费层级。我这里要求先充值，我充了 5 刀。

新账号开完会看到“已获得 300 美元赠金”。那 5 刀留在余额里，之后 AI Studio 的调用照样能用。

### 2. 启用 Vertex AI API

打开 console.cloud.google.com，左上角选中**刚才关联了结算的那个项目**，搜 Vertex AI，按提示启用 API。

### 3. 建一个 API 密钥，绑定服务账号

「API 和服务 → 凭据 → 创建凭据 → API 密钥」。

页面会让你选一个服务账号来绑定。列表里可能已经有 AI Studio 自动建的 `ais-gemini-key-…`，选它们可以，自己新建一个也可以。

系统已经默认将聊天和语音分类，所以两个功能都要接的话需要建两个，各绑一个服务账号。注意账单是按项目算的，不会按密钥拆开显示。

### 4. ⚠️ 给服务账号加权限（最大的坑）

光有密钥不够。服务账号默认没有调 Vertex 的权限，直接用会报：

```
403 Permission 'aiplatform.endpoints.predict' denied
```

去「IAM 和管理 → IAM → 授予访问权限」：

- 新的主账号：粘贴服务账号的邮箱
- 角色：**Agent Platform User**

坑在这里：网上教程都写选 “Vertex AI User”，但它已经改名了，**搜 Vertex AI User 搜不到**，搜出来的全是 Service Agent 之类不相干的角色。

改搜它的内部名字 `aiplatform.user`，出来的 **Agent Platform User** 就是它。

两个服务账号就各加一次。

刚加完可能还会 403 一阵子。我这边一个几秒就通了，另一个等了几分钟。不用改配置，一会就好。

### 5. 先用命令行测一下（可选）

把 `你的密钥` 换掉：

```bash
curl -H "x-goog-api-key: 你的密钥" -H "Content-Type: application/json" \
  "https://aiplatform.googleapis.com/v1/publishers/google/models/gemini-2.5-flash:generateContent" \
  -d '{"contents":[{"role":"user","parts":[{"text":"Say hi in one short sentence."}]}]}'
```

返回里能看到 `"text"`，就通了。

### 6. 填进前端

前端里新建一个 **Gemini 格式**的连接：

- 地址：`https://aiplatform.googleapis.com/v1/publishers/google`
- 密钥：上面建的
- 模型名：需手填，比如 `gemini-2.5-flash`

我实测这个地址允许浏览器跨域直连，纯网页前端也能用，不需要另外搭中转。

前端要满足两点：一是按 `地址/models/模型名:generateContent` 拼请求，二是用 `x-goog-api-key` 请求头放密钥。如果只支持 OpenAI 格式，这条路就走不通了。

## 怎么确认扣的是赠金

费用不是实时显示的，要等几个小时，最长一天左右。

控制台 → 结算 → 报告，按服务看。我这次的账单：

| 服务 | 费用 | 赠金抵扣 | 小计 |
|---|---|---|---|
| Vertex AI | $0.35 | -$0.35 | $0.00 |
| Gemini API（AI Studio） | $0.006 | — | $0.01 |

Vertex 那行被抵成 0，就说明成功了。（AI Studio 扣的是我接通Vertex前测试的钱。）

## 注意

- 赠金只给新的 Google Cloud 结算账号，并且有有效期。具体哪天到期，在「结算 → 赠金」里能看到。
- 赠金用完或者过期后，会转成按量从卡里扣钱。建议在「结算 → 预算和提醒」设一个低额提醒，比如 5 刀。
- 免费试用阶段不能给虚拟机加 GPU，也不能挖矿，第三方市场的部分软件也不能用赠金买。

除了聊天，这笔赠金还能用在 Google 的语音合成、语音转文字、Cloud Run（小型托管服务）这些服务上。我还没逐一试，试过了再来补。
